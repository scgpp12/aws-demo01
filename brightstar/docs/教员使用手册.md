# BrightStar（ブライトスター）培训助手 · 教员使用手册

> 版本：v2.x（微信 + LINE agent 版）　更新日期：2026-06-16
> 适用对象：授课教员 / 课程运营
> 一句话：**学员在微信或 LINE 里和「培训助手」聊天就能报名上课；老师用几条文字命令就能建课、查名单、分组；课程网站用登录码进入，可记成绩和课后问卷。**

---

## 1. 这套系统是什么

- **学员端**：微信里的「**㍿ブライトスター研修アシスタント**（BrightStar 研修アシスタント）」客服号，**或 LINE 公式账号**「ブライトスター研修アシスタント」。两个平台功能完全一样，学员用哪个都行。
- **老师端**：同一个客服号里发**文字命令**（如「建课 …」）即可管理课程，无需后台、无需电脑。
- **课程网站**：学员用「登录码」登录，看课程讲义、做随堂测验和课后问卷；成绩按人记录，老师可导出。
- **语言**：支持 **日本語 / 中文**，学员首次进来自己选，**默认日语**。所有回复都按学员选择的语言显示。
- **自动提醒**：开课**前 1 小时**自动给已报名学员推送上课提醒。

> 说明：目前 **Zoom 为演示占位**（发布课程会生成一个模拟会议链接）。正式 Zoom 接入开通后，链接会变成真实会议地址，操作方式不变。

## 2. 三种身份 / 三个入口

| 身份 | 在哪里操作 | 能做什么 |
|---|---|---|
| 学员 | 微信客服号 或 LINE 公式账号聊天 | 注册、看课、报名/取消、查下节课、拿登录码、跨平台关联 |
| 老师 | 同一个客服号聊天（发命令） | 建课、发布、改课、删课、查学员、名单、随机分组 |
| 网站访客（学员/老师） | 课程网站，用登录码登录 | 看讲义、做测验/问卷；老师可导出成绩 |

> 一个人可以**同时是老师和学员**：老师认证后依然能像学员一样报名上课。

## 3. 学员怎么用（请教员先了解，便于指导学员）

学员第一次和客服号说话，会经历 3 步：

1. **选语言**：系统提示「请选择语言 / 言語を選んでください　1️⃣日本語　2️⃣中文」，回复数字即可（不选直接发名字也行，默认日语）。
2. **填姓名**：回复**真实姓名**（2–20 字）。姓名会用于成绩和点名，请如实填写。
3. **完成**，进入主菜单。

> 🔗 **微信和 LINE 是同一个人？** 默认两平台各算一个账号。让学员在已注册的平台发「**登录码**」拿到 8 位码，再到另一平台发「**绑定 <登录码>**」（日：「連携 <code>」），即可合并成同一账号——报名、登录、提醒都打通，不会重复。**注册第一屏也会提示这个入口。** 老师的「学员列表」已自动去重，不会因关联而重复显示。

之后随时可用的操作（打字或回复数字均可）：

| 想做的事 | 回复数字 | 也可以直接打字（中/日） |
|---|---|---|
| 看有哪些课 | `1` | 有哪些课 / 講座一覧 |
| 看我报了哪些课 | `2` | 我的课程 / マイ講座 |
| 看下节课时间+链接 | `3` | 下节课 / 次の講座 |
| 报名 | — | `报名 课程名` / `申込 講座名` |
| 取消报名 | — | `取消 课程名` / `キャンセル 講座名` |
| 拿网页登录码 | — | `登录码` / `ログインコード` |
| 改自己的名字 | — | `改名 新名字` / `名前変更 新しい名前` |
| 切换语言 | — | `语言` / `言語`（再回「中文」或「日本語」） |

> **退课截止**：默认开课前 **2 小时**之后不能取消。
> **登录码有效期**：**7 天**，过期后再发一次「登录码」即可拿到新的。

## 4. 老师怎么用（重点）

### 4.1 先把自己变成「老师」

在客服号里发一条：

```
老师认证 BS-TEACHER-2026
```

> `BS-TEACHER-2026` 是**老师认证口令（内部保密，请勿发给学员）**。认证成功后你就有了老师权限，且仍可作为学员报名。
> 如果你已被加入老师白名单，则无需认证，直接发命令即可。

发 `老师帮助` 任何时候都能看到命令清单。

### 4.2 老师命令清单

> 命令格式里的 `|` 是**竖线分隔符**，请照抄。时间一律用 **JST（日本时间）**，格式 `年-月-日 时:分`。

#### ① 建课（先建草稿）
```
建课 标题|开课时间|时长(分钟)|容量|简介
```
例：
```
建课 Python入门|2026-06-20 14:00|90|20|零基础也能学
```
- 成功后回复「✅ 已创建草稿…」。**此时学员还看不到**，需要下一步「发布」。

#### ② 发布（生成 Zoom 链接并对学员开放）
```
发布 Python入门
```
- 回复里包含**主持人链接（仅你可见）**和**学员 Zoom 链接**。发布后学员才能在「课程列表」里看到并报名。
- （当前 Zoom 为演示占位，链接是模拟地址。）

#### ③ 改课（修改已建课程）
```
改课 课程名|字段=值
```
可改字段：**标题 / 简介 / 容量 / 时长 / 开课时间**。多个字段用 `;` 隔开。
例：
```
改课 Python入门|容量=30
改课 Python入门|开课时间=2026-06-21 10:00;容量=25
```

#### ④ 删课
```
删课 Python入门
```

#### ⑤ 看所有学员
```
学员列表
```
- 列出已注册学员及其身份（学员 / 老师）。

#### ⑥ 看某门课的报名名单
```
名单 Python入门
```

#### ⑦ 随机分组
```
分组 Python入门|组数=4
```
或按每组人数：
```
分组 Python入门|每组=5
```
- 系统会把报名学员**随机均分**成若干组并列出每组成员。重新发命令会**重新随机**。

### 4.3 老师注意事项
- 课程名支持**模糊匹配**：发命令时课程名写一部分即可，但若匹配到多门会提示你写具体些。
- 建课后**记得「发布」**，否则学员看不到。
- 时间务必用 **JST** 和 `2026-06-20 14:00` 这种格式，否则会提示格式错误。

### 5.2 学员在网站能做什么
- 看课程讲义（第 1 课 Amazon S3 等），右上角可切 **日本語 / 中文**、深色模式、🎨配色；宽屏左侧有大纲快速跳转。

## 6. 自动提醒
- 开课**前约 1 小时**，系统自动通过微信客服号给**已报名学员**推送提醒（含时间和 Zoom 链接）。
- 限制：微信平台规则要求「学员近 48 小时内与客服号有过互动」才能主动推送；长期未互动的学员可能收不到（这是平台限制）。

## 7. 常见问题（FAQ）

**Q：学员说收不到回复 / 回复慢？**
A：偶发慢属正常（首次唤醒）。若持续无回复，联系技术员查看（可能是中转/网络）。

**Q：学员名字填错了怎么办？**
A：让学员发「`改名 正确名字`」即可自行更正；或老师代为说明。

**Q：学员登录网站提示"登录码无效"？**
A：多半是**超过 7 天过期**了。让学员在微信重新发「登录码」拿新的。

**Q：建了课学员看不到？**
A：忘了**发布**。发「`发布 课程名`」。

**Q：想让学员用日语还是中文？**
A：学员自己选，默认日语。随时发「语言/言語」可切换。
